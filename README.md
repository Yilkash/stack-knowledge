# StackKnowledge 🎓

**StackKnowledge** is a decentralized educational platform built on the Stacks blockchain. It incentivizes the sharing of high-quality academic resources (past questions, handouts) and features an AI-powered study assistant that provides answers strictly based on the uploaded materials.

## 🚀 Vision
To create a "Share-to-Earn" knowledge base where:
-   **Students** get accurate, verifiable answers from their specific course materials.
-   **Contributors** earn STX tips and reputation for uploading valuable content.
-   **Data** is secured and owned by the community via Stacks JS and Gaia.

## ✨ Key Features
-   **Smart Registry:** On-chain record of all educational resources.
-   **Crypto Tipping:** Direct P2P tipping in STX to content creators.
-   **AI Study Buddy (RAG):** Chat offering context-aware answers from your PDFs.
-   **Premium UI:** A modern, glassmorphism-inspired interface for a seamless study experience.

## 🛠 Tech Stack
-   **Frontend:** Next.js, Tailwind CSS, Lucide Icons
-   **Blockchain:** Stacks (Clarity Smart Contracts)
-   **AI:** OpenAI (RAG Pipeline)
-   **Storage:** Stacks Gaia / IPFS

## 📦 Installation

```bash
# Clone the repository
git clone https://github.com/your-username/stack-knowledge.git

# Install dependencies
npm install

# Run the development server
npm run dev
```
